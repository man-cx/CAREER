# Pricerite (2017)

Pricerite is a Hong Kong household-goods and furniture retail chain. In 2017 TTG, a SAP partner, implemented SAP Cloud for Customer (C4C) as its CRM for the customer care centre, shop sales and custom-made furniture teams. Man was a Senior CX Consultant at TTG.
