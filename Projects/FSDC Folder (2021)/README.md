# FSDC (2021)

Novus Consulting's work for the Financial Services Development Council (FSDC), the Hong Kong body that promotes the city's financial services industry. The engagement covered FSDC's SAP Sales Cloud and Marketing Cloud CRM subscription, the Zoom event integration and the TAP scoring system, plus ongoing maintenance. Man was CX Project Director.
