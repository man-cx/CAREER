# TravelNoMore (2016)

TravelNoMore (自邮行) was the retail brand of Hengfeng (Hong Kong) Cross-border E-commerce, a cross-border e-commerce venture in Guangzhou's Nansha free-trade zone. Kingdee delivered the K/3 Cloud business system behind it — purchasing, warehouse, online shop, POS tills, membership and customs — from 2015 through the store opening in April 2016. Man was Hengfeng's internal IT manager on the project.
