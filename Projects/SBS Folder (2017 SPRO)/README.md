# SBS (2017)

Client: SBS 浔兴拉链 (SBS Zipper), a zipper manufacturer in Fujian, China. In 2017 the consultancy SPRO (爱思普) delivered phase one of a dealer and channel management system built on SAP Cloud for Customer, covering dealers, quotations, sales orders and after-sales service. Man was CX Project Director.
