# Issues

Outstanding issues and follow-up items.

## Usage

- Create one file per issue using `issue-template.md`
- Name files as `ISSUE-<NNN>-<short-slug>.md` (running number, e.g. `ISSUE-001-reply-jsm.md`)
- Date is recorded in the file frontmatter, not the filename

## Status Key

| Status | Meaning |
|--------|---------|
| `open` | Needs attention |
| `in-progress` | Being worked on |
| `blocked` | Waiting on external input |
| `resolved` | Done — move to `closed/` |
