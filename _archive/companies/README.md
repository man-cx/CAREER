# Companies

Company profiles and project registry — single source of truth for all companies and projects in this workspace.

## Usage

- Company profiles: `companies/<shortcode>/README.md`
- Each profile includes team contacts, project details, and cross-references
- Link related companies with `[[Company Name]]`
- New company: copy `company-template.md` into a new subfolder as `README.md`
