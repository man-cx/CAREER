# Meetings

## Structure
```
meetings/
├── README.md
├── meeting-template.md        # Template for new meeting files
└── minutes/                   # Finished meetings with full minutes
```

## Workflow
1. Create a new meeting file at the top level using `meeting-template.md`
2. When the meeting is done and minutes are filled in, move it to `minutes/`

## Template
`meeting-template.md` — copy and fill in when scheduling a new meeting.

## Rules
- Filename: `YYYY-MM-DD_topic.md`
- Each file must include: date, attendees, agenda, notes, decisions, actions

## Contents
| File | Description |
|------|-------------|
| `meeting-template.md` | Template for new meeting files |
| `minutes/` | Finished meetings with full minutes |
