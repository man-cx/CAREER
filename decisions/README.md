# Decisions

Key decisions made across projects. Each decision is a standalone file.

## Usage

- Create new decisions from `decision-template.md`
- Name files as `DECISION-<NNN>-<short-slug>.md` (running number)
- Date is recorded in the file frontmatter, not the filename

## Status Key

| Status | Meaning |
|--------|---------|
| `proposed` | Under discussion |
| `accepted` | Approved and active |
| `superseded` | Replaced by a newer decision |
| `deprecated` | No longer applicable |
