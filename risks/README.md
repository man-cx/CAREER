# Risks

Project and operational risks. Each risk is a standalone file.

## Usage

- Create new risks from `risk-template.md`
- Name files as `RISK-<NNN>-<short-slug>.md` (running number)
- Date is recorded in the file frontmatter, not the filename

## Status Key

| Status | Meaning |
|--------|---------|
| `identified` | Recognized, not yet assessed |
| `assessed` | Impact and likelihood evaluated |
| `mitigated` | Controls in place |
| `accepted` | Acknowledged, no further action |
| `closed` | No longer relevant |

## Risk Matrix

| Likelihood →<br>Impact ↓ | Low | Medium | High |
|---------------------------|-----|--------|------|
| **High** | Monitor | Mitigate | Escalate |
| **Medium** | Accept | Monitor | Mitigate |
| **Low** | Accept | Accept | Monitor |
